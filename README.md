## 🚧 Currently Working On

### ❤️ Near — Long-Distance Relationship App

**Flutter • Django REST Framework • PostgreSQL • Docker • JWT**

A full-stack mobile application I'm currently developing for couples in long-distance relationships.

The app brings different relationship activities into one private shared space.

**Key features:**

- ❤️ Couple pairing and private shared space
- 📸 Daily photo sharing
- 💬 Daily questions
- 📅 Date invitations
- ⏳ Relationship countdowns
- 🖼️ Shared memories
- 😊 Mood sharing
- 💌 "Open When" messages
- 🗺️ Shared experiences and plans
- 🔐 JWT authentication and protected APIs

This project is helping me gain practical experience with **mobile development, backend APIs, authentication, databases, Docker, and full-stack application architecture**.

🔗 [View Repository](https://github.com/Alihansagat/Near)
